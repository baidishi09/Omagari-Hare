# 0.1.1 验证记录

验证日期：2026-11-24。环境：Windows 11 x64（22631）、主屏 125% 缩放、Node.js 22.15.0、Electron 45.4.1。

## 已通过

- `npm run check`：所有程序脚本语法、图集尺寸与每帧时长合同。
- `npm test`：22 项测试；设置校验、负坐标/小屏几何、自动往返、连续闲置去重、输入打断、手动宽限、暂停、睡眠恢复、工作区变化，以及连接状态、保存错误顺序、真实动作确认、隐藏预览过期、暂停呼吸和重复反馈播报的计时器清理。
- `npm run test:integration`：启动真实 Electron 主进程和透明窗口，读取 Canvas 非透明像素，确认沙箱、上下文隔离与不抢焦点；模拟系统闲置 599/600 秒，验证真实窗口完整往返与再次闲置；验证方向动画、任务栏边界、暂停、设置变更、锁屏/睡眠/恢复事件、拖动和屏幕变化；关闭设置后宠物继续存在；重启同一临时资料目录恢复阈值和停靠点。
- 首版的原生 Windows 界面检查已验证设置控件与手动散步；当前工位界面由下述真实 Electron UI 测试和截图检查覆盖。
- 场景界面改版后 `npm run test:ui` 通过：首页隐藏参数表单、原生抽屉、Escape/焦点恢复、便签入口、输入保存、真实挥手/跳跃动作 token、移动时操作保护、减少动态效果、800×640 布局和保存失败回滚，均在隔离资料目录的真实 Electron 中验证。新版再次通过完整 `test:integration`。
- 0.1.1 的 UI 回归另覆盖：滑块拖出抽屉不误关、背景完整点击关闭；聚焦的显示器选项在保存广播与列表变更中保持；保存失败不覆盖新草稿；暂停/解锁后等待输入提示；120 分钟数字不裁切；两种窗口尺寸的长错误提示不碰其他内容。无渲染进程异常。
- `npm run test:layout`：1000×790、800×640、1280×720、1440×900 四种原生窗口尺寸，分别在 100% 和 200% 缩放下通过。检查桌面平面锚点与脚底误差小于 1 CSS px、元素无碰撞、正文/按钮字号、横向边界，以及高缩放时页面和抽屉所有控件可滚动到达。报告保存于忽略提交的 `test-results/layout/report.json`。
- 1000×790 和 800×640 的 200% 缩放下，逐个滚动到动作按钮并点击，再显示 60 字长错误，确认提示完整落在可见视口内，且不遮挡问候、便签、头部和操作栏。使用 Electron 原生 `capturePage` 保存并目视检查高缩放截图。
- 安装版登录项验证使用 `getLoginItemSettings` / `setLoginItemSettings` 模拟接口，覆盖共享配置不同步、显式取消、系统中移除及写入失败回滚；没有增删真实 Windows 启动项。
- 打包后的 `release/win-unpacked/Omagari Hare.exe` 已验证 `app.isPackaged`、默认设置、内置精灵加载与手动散步；无需开发服务器或 Codex。
- 前一轮安装依赖时的 `npm audit` 为 0 已知漏洞；本轮没有更换依赖版本。打包工具的 minimatch 依赖通过限定 overrides 升级，避免降级 Electron 或全局替换旧 API。

集成测试使用项目内的独立临时资料目录，不修改日常用户设置。为缩短执行时间，闲置读数、电源事件与较窄的测试工作区由测试注入；没有让电脑实际闲置十分钟或执行系统锁屏。多屏插拔、不同任务栏位置和其他缩放比例仍需相应硬件人工验证。

## 修复记录

- 设置速度、穿透或置顶时保留当前路线，仅尺寸/屏幕/停靠点变化重算几何。
- 鼠标离开注视范围后清除旧视线，恢复待机呼吸。
- 拖动捕获丢失、锁屏或显示器变化能结束拖动；主进程确认状态防止旧消息提前中断新拖动。
- 125% 缩放会使原生窗口返回的尺寸比请求值多 1 DIP。移动时始终传入原始尺寸，避免累积扩大；保存最近请求以免静止时重复定位，并留 1 DIP 的任务栏安全余量。
- 工位场景的角色脚底跟随背景实际缩放与裁切，站在桌面内部；200% 缩放使用可滚动布局，避免缩小文字或裁掉操作。
- 连接成功前不使用演示数据冒充真实状态，统一状态优先级；操作回执缺失时重新读取状态，不虚构挥手成功。
- 修复保存回执覆盖草稿、不同字段错误被掩盖、聚焦屏幕选项重建跳回默认，以及最小化后继续播放已过期动作。

安装包目前没有代码签名；尚未实际安装 NSIS 包或更改 Windows 登录启动设置。程序以本地动画和系统闲置时长工作，未引入在线服务。

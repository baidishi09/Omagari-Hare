# 0.1.0 验证记录

验证日期：2026-11-24。环境：Windows 11 x64（22631）、主屏 125% 缩放、Node.js 22.15.0、Electron 45.4.1。

## 已通过

- `npm run check`：所有程序脚本语法、图集尺寸与每帧时长合同。
- `npm test`：12 项测试；设置校验、负坐标/小屏几何、自动往返、连续闲置去重、输入打断、手动宽限、暂停、睡眠恢复和工作区变化。
- `npm run test:integration`：启动真实 Electron 主进程和透明窗口，读取 Canvas 非透明像素，确认沙箱、上下文隔离与不抢焦点；模拟系统闲置 599/600 秒，验证真实窗口完整往返与再次闲置；验证方向动画、任务栏边界、暂停、设置变更、锁屏/睡眠/恢复事件、拖动和屏幕变化；关闭设置后宠物继续存在；重启同一临时资料目录恢复阈值和停靠点。
- 原生 Windows 界面检查：设置窗口完整显示控件与底部说明；实际点击“现在去散步”后状态变为“正在散步，去看看右边”。
- 安装依赖时的 `npm audit`：0 已知漏洞；打包工具的 minimatch 依赖通过限定 overrides 升级，避免降级 Electron 或全局替换旧 API。

集成测试使用项目内的独立临时资料目录，不修改日常用户设置。为缩短执行时间，闲置读数、电源事件与较窄的测试工作区由测试注入；没有让电脑实际闲置十分钟或执行系统锁屏。多屏插拔、不同任务栏位置和其他缩放比例仍需相应硬件人工验证。

## 修复记录

- 设置速度、穿透或置顶时保留当前路线，仅尺寸/屏幕/停靠点变化重算几何。
- 鼠标离开注视范围后清除旧视线，恢复待机呼吸。
- 拖动捕获丢失、锁屏或显示器变化能结束拖动；主进程确认状态防止旧消息提前中断新拖动。
- 125% 缩放会使原生窗口返回的尺寸比请求值多 1 DIP。移动时始终传入原始尺寸，避免累积扩大；保存最近请求以免静止时重复定位，并留 1 DIP 的任务栏安全余量。

安装包目前没有代码签名；尚未实际安装 NSIS 包或更改 Windows 登录启动设置。程序以本地动画和系统闲置时长工作，未引入在线服务。

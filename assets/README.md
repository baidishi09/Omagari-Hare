## 使用约定

- 图集每格 `192 × 208`，每行 8 格；第 0–8 行为动作，第 9–10 行为 16 个视线方向。未使用的格子透明，不得加入动画序列。
- `durations` 单位为毫秒，其长度就是动作帧数。帧序从列 0 开始；待机周期为 6.6 秒。
- 固定脚底基线 `feetY=201`，单元底部保留 7px 透明余量。绘制原点应使用 `任务栏上沿 − feetY × scale`，避免角色悬空。
- `running-right` / `running-left` 才是左右移动。`running` 是继承的历史资源名，画面实际为低头在掌心描圈思考，不能用于横向移动。
- 左右方向分别绘制，不应水平镜像。角色的黑色 X 发卡有固定侧别。
- 移动与跳跃帧的脚底高度变化是动作内容，不要逐帧裁切或强行贴地。
- 视线以屏幕正上方为 0°，顺时针递增：90° 右、180° 下、270° 左。视线帧是离散姿势，不是无缝转头动画。
